# Otijot

Пишем на иврите символами других письменностей Юникода, которые выглядят как ивритские буквы.
Текст по-прежнему читается как иврит, но состоит из «чужих» символов: харошти, набатейского, батак, ханифи и так далее.

Идея родилась в переписке с Kobi в октябре 2025 года. Его версия:
[pakala.vip/jad](https://pakala.vip/jad) (ранняя — [pakala.vip/heb](https://pakala.vip/heb)) и Google-таблица
«Hebrew-Fake-Cursive-only-R2L». Здесь мы собираем свою таблицу с нуля, а его выбор служит лишь кандидатами.

## Файлы

- `index.html` — конвертер: ввод на иврите → текст из похожих символов, кнопка «Копировать».
- `table.html` — редактор таблицы: все кандидаты крупно, клик выбирает символ для буквы,
  отметки «отображается на Android / iOS / WhatsApp», экспорт в JSON.
- `mapping.json` — сама таблица (данные отдельно от кода). У каждой буквы, включая конечные ך ם ן ף ץ,
  есть `chosen` (сейчас пусто) и `candidates` с `char`, `cp`, `name`, `bidi`, `source` и флагами платформ.
- `scripts/seed.py` — генерирует стартовый `mapping.json` из трёх источников:
  `kobi-site`, `kobi-sheet`, `mark-2025-10-17`. Перезапуск затирает выбор, так что запускать только для пересборки с нуля.

## Как работать

```bash
python3 -m http.server 8000   # из папки проекта
# http://localhost:8000/table.html — выбираем символы
# «Скачать JSON» → заменить mapping.json → git commit
```

Правки в `table.html` сохраняются черновиком в браузере (localStorage). Конвертер на той же машине
сразу их видит. В репо попадают только после замены `mapping.json`.

## Направление письма

Символы, у которых bidi-класс не `R`/`AL` (батак ᯄ, латинская ʆ и т. п.), оборачиваются по одному
в `U+202E … U+202C` (RLO…PDF). Если завернуть всю строку целиком, развернутся и цифры с латиницей.
Само преобразование делается в поле вывода, а не в поле ввода: с bidi-символами в поле ввода ломается backspace.
